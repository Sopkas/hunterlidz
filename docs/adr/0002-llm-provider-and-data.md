# ADR-0002. Поставщик LLM и какие данные ему уходят

**Статус:** предложено — требуется решение владельца проекта (TECHNICAL.md: «ещё не выбраны поставщик LLM, тариф»).
**Дата:** 2026-09-27.

## Контекст

В ходе разработки для живых проверок использовался бесплатный тариф Google Gemini (`gemini-flash-lite-latest`): у Anthropic не было баланса. Бесплатный тариф Google может использовать запросы для обучения. В прототипе в запрос уходили контакты лидов. Лимит затрат отсутствовал. Это решение не было согласовано.

## Решение (предлагаемое)

1. Поставщик и тариф выбирает владелец проекта. Код поддерживает оба варианта через `HUNTER_LLM=gemini|claude`, других зависимостей выбор не требует.
2. **Контакты модели не передаются никогда** (email, телефон, Telegram маскируются в `domain/privacy.py`, тест `test_contacts_never_reach_the_model`); модели нужны факты о компании и потребности, а не адреса.
3. **Лимит затрат обязателен** (doc 12): без тарифа, `COST_CURRENCY`, `RUN_COST_CAP`, `DAILY_COST_CAP` research не запускается (код 2). Бесплатный тариф задаётся явно ценой 0.
4. Для реальных данных клиентов рекомендуется платный тариф без обучения на запросах; бесплатный — только для синтетики и публичных объявлений.

## Последствия

Выбор провайдера — настройка, а не изменение кода. До решения владельца боевые данные через бесплатный тариф не прогонять.
