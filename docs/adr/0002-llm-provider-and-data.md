# ADR-0002. Поставщик LLM и какие данные ему уходят

**Статус:** принято командой 2026-09-27 в части провайдера; тариф и лимиты утверждает владелец проекта.

## Решение

1. Единственный поставщик модели — **Anthropic Claude** (официальный SDK, `infrastructure/llm/claude.py`). Других провайдеров в коде нет; их подключение — только новым ADR.
2. **Контакты модели не передаются никогда**: email, телефон и Telegram маскируются в `domain/privacy.py` перед любым вызовом (тест `test_contacts_never_reach_the_model`). Модели нужны факты о компании и потребности, а не адреса.
3. **Тариф и лимит затрат обязательны** (doc 12): без `ANTHROPIC_API_KEY`, цены за 1M токенов (больше нуля), `COST_CURRENCY`, `RUN_COST_CAP`, `DAILY_COST_CAP` модель не вызывается (код 2).
4. Модель по умолчанию — `claude-haiku-4-5`; другая задаётся `HUNTER_CLAUDE_MODEL`.

## Последствия

Адаптер Claude пока не проверен на живом ответе (не было баланса): схема ответа взята из документации SDK и помечена как предполагаемая. Первый живой прогон — на синтетических данных, результат записать в журнал.
