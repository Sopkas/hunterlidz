# Аудит соответствия правилам «Как мы работаем»

Дата: 2026-09-27. Объект: стек веток `claude/H-01` … `claude/H-11`. Проверка частично автоматическая (команды ниже), частично ручная. Отчёт подготовлен ИИ-агентом.

Обозначения: ✅ соблюдено · 🔧 нарушение найдено и исправлено коммитом аудита · ⚠️ частично / требует решения человека · ❌ не соблюдено.

## 01. Процесс

| Правило | Статус | Чем подтверждено |
| --- | --- | --- |
| Задачу назначает человек, агент называет её и ждёт «да» | ✅ | Объём (весь v0), ID из backlog doc 13 и способ передачи документов выбраны пользователем до начала работы |
| ID задачи сквозной: ветка, коммиты, PR, журнал | ⚠️ | Использованы ID backlog doc 13 (H-01…H-11), а не ID карточек YouGile (S1-05 …): доступа к YouGile нет. Сопоставить при заведении карточек |
| Оценка задачи 2–8 часов, большую задачу делят | ❌ | H-05, H-07, H-09 по объёму больше 8 часов. Делить задним числом не стали, чтобы не переписывать историю; для следующих задач — делить |
| Закрытие задачи = сверка приёмки, флаг, комментарий | — | Выполняет владелец задачи в YouGile после ревью и merge |
